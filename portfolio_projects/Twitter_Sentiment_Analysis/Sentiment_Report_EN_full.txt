======================================================================
TWITTER SENTIMENT ANALYSIS — COMPREHENSIVE REPORT
======================================================================

1. EXECUTIVE SUMMARY
--------------------
Dataset size: 1,600,000 tweets (sampled 50,000 stratified).
Sentiment split: 50.0% positive, 50.0% negative.
Average tweet length: 73.8 characters.
Best performing model: Logistic Regression with AUC = 0.8365.

2. EXPLORATORY ANALYSIS
-----------------------
The sentiment distribution is approximately balanced in the full dataset. Tweet lengths follow a right-skewed distribution with a mode around 50–70 characters. Negative tweets tend to be slightly longer on average. The most frequent tokens for each class reflect expected polarity patterns (positive: "good", "love", "thanks"; negative: "hate", "sad", "miss").

3. FEATURE ANALYSIS
-------------------
Chi-square test identifies highly discriminative unigrams:
  Positive-associated: thanks, love, good, thank, great, happy, welcome, quot
  Negative-associated: sad, work, miss, sick, hate, wish, sorry, want, school, bad

Top unigrams (by chi-square, per class):
  Positive: thanks, love, good, thank, great, happy, welcome, quot
  Negative: sad, work, miss, sick, hate, wish, sorry, want

Top bigrams (by chi-square, per class):
  Positive: good morning, great day, happy birthday, thanks follow, good night, good luck, hope great, welcome twitter
  Negative: sorry hear, school tomorrow, feel like, don want, going miss, im lonely, lonely company, company female

TF-IDF top features for positive class: good, thanks, just, love, day, quot, going, twitter, like, lol
TF-IDF top features for negative class: work, just, day, today, going, like, want, don, miss, got

7. CONCLUSIONS
--------------
- Logistic Regression provides the strongest performance for this task.
- Lexical features (TF-IDF unigrams) capture sentiment effectively.
- Bigrams add marginal value over unigrams for this dataset.
- The balanced class distribution makes accuracy a reliable metric.
